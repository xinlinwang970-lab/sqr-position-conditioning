# Third-party references and data

This is an independent implementation. The pre-existing project notice states that upstream source files were not pasted into the implementation. This preparation preserves that attribution statement; it does not independently establish the full development history of every line.

Technical references include:

- Xu, Yuetonghui; Wang, Yiwen; Wu, Xihong; Li, Xiaobing; Yu, Feng. [Position also matters! Separating Same Instruments in String Quartet using Timbral and Positional Cues](https://www.isca-archive.org/interspeech_2025/xu25b_interspeech.html), Interspeech 2025, pp. 3105–3109, DOI 10.21437/Interspeech.2025-130.
- [String Quartet Set with Reverb](https://zenodo.org/records/14793971), DOI 10.5281/zenodo.14793971. Download data directly from its publisher. No dataset audio is included here.
- [ws-choi/Conditioned-Source-Separation-LaSAFT](https://github.com/ws-choi/Conditioned-Source-Separation-LaSAFT), technical architecture reference. The historical local notice records reference commit `4e1c0609ccd7cab1f992f3078bade313879efdca`, MIT license, copyright 2020 ws-choi.
